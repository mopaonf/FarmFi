# FarmFi (AgriVest) – Decentralized Agricultural Funding Platform

FarmFi is a decentralized funding platform designed to support agricultural projects through wallet-based investment tracking and transparent funding management. The platform aims to connect investors with agricultural initiatives in a secure and organized way.

## Features
- Agricultural project listings
- Wallet-based investment tracking
- User authentication
- Investment monitoring dashboard
- Funding management system
- Responsive web and mobile interface

## Technologies Used
- React.js
- React Native
- Node.js
- MongoDB
- Express.js

## Project Goals
The project was created to explore how technology and decentralized finance concepts can support agricultural development and improve funding accessibility.
